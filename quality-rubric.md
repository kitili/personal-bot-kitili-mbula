# Quality rubric — Princess Palace wrap-up

**What is scored:** the Daily Wrap-Up markdown the bot returns after notes are run.  
**Who reads it:** Kitili (end-of-day reflection / LMS logs).

A good wrap-up scores **yes** on all five lines:

1. Has exactly three sections titled `## Done`, `## Doing`, and `## Next` (in that order).
2. Every bullet under those sections starts with `- ` (markdown list).
3. No section has more than 5 bullets.
4. Bullets are concrete actions or outcomes (not vague filler like "stuff" or "things").
5. Includes a footer line that mentions `daily-wrap-up` or the trigger/timestamp.

Score each sample **yes/no per line**. A wrap-up "passes" only if all five are yes.
