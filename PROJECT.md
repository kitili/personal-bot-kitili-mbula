# Kitili's Princess Palace Bot — Project Description

**Student:** Kitili Mbula  
**Course:** Taleemabad University (Modules 6–7)  
**Live:** https://personal-bot-kitili-mbula.netlify.app  
**Repo:** https://github.com/kitili/personal-bot-kitili-mbula

## What it is

A girly personal bot — **Princess Palace** — that turns messy work notes into a short **Done / Doing / Next** wrap-up, then wraps the whole day in pink & yellow: morning intentions, mood tracking, sparkle stickers, a diary, and affirmations. Built first as a Claude Code skill + loop + hook (Module 6), then as a logged-in web app with pony, doll, and castle companions (Module 7).

## Why it exists

During Silverleaf and Taleemabad coursework, notes piled up across projects. This bot keeps end-of-day reflection automatic — same format every time — while making the habit feel soft, fun, and worth opening.

## Features

- **Morning Board** — what I want, how I'm doing, exactly five to-dos
- Daily Wrap-Up (merges unfinished board to-dos; optional AI polish)
- Focus timer (25/5) + soft habits
- Mood Garden + streak tracking
- Sparkle points → unlockable princess sticker album
- Diary search, weekly review, full backup/restore
- PWA install + offline shell, keyboard shortcuts
- Login-gated web UI (Netlify)

## Stack

- Claude Code skill / loop / hook
- Express + cookie-session + Netlify Functions
- Pink/yellow UI with custom princess art
